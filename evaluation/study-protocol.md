# PASS 설명 비교 파일럿 v3 — 사전·사후 설문

## 연구 목적과 측정 개념
예산 변화에 대한 비교 설명이 추천 결과 이해도, 선택 확신, 주관적 판단 부담에 미치는 영향을 탐색한다. 기능의 효과가 이미 검증되었다고 가정하지 않는다.

| 개념 | 측정 |
| --- | --- |
| 추천 결과 이해도 | 첫 추천 변화, 후보 수 변화의 객관식 정답 여부; 선택적인 한 문장 설명 |
| 선택 확신 | 조건에 맞는 선택이라는 확신의 5단계 평정. 미선택자는 미선택 판단에 대한 확신으로 구분 |
| 판단 부담 | 상품 판단 과정의 어려움 5단계 평정 |

SUS는 전체 시스템 사용성, NASA-TLX는 다차원 작업 부하를 측정하는 도구로 검토했다. 이번 좁은 설명 비교 파일럿에는 과제별 이해도 질문과 자체 평정 문항을 사용한다. 표준 척도 일부를 사용하거나 변형한 설문이 아니며, SUS/NASA-TLX 점수 또는 동일한 타당도·신뢰도를 주장하지 않는다. 실제 참가자를 모집하기 전에 파일럿으로 표현과 절차를 확인한다.

## 비교 설계
- A: 상품 가격과 기본 추천 근거. B: 동일 정보에 두 예산의 비교 설명 추가.
- 동일 과제와 예산에서 후보·순위·버튼은 동일하다.
- 각 참가자가 A/B를 모두 사용하는 참가자 내 설계. 4개 과제·조건·순서 조합으로 무작위 배정한다. 작은 표본의 조별 인원 균등을 자동 보장하지 않는다.
- 부모님 선물 하나: 배송비 포함 30,000→42,000원, 덜 단 선호, 견과류 제외.
- 친구 선물 하나: 배송비 포함 60,000→72,000원, 덜 단 선호, 커피 제외.
- 두 과제 모두 후보가 증가하되 최상위 추천은 유지된다. 결론을 추천이 바뀌는 상황이나 자유 대화 성능에 일반화하지 않는다.
- Gemini 호출 없이 고정 카탈로그로 평가한다. API 한도는 평가 수행에 영향을 주지 않는다.

## 참여 흐름
1. 수집 항목과 중단·파일 전달 방식을 안내한다. 무작위 세션 ID를 사용한다.
2. 사전 설문 5개: 연령대(응답 거부 가능), 최근 6개월 온라인 구매 빈도, 최근 1년 명절 선물 선택 경험, 챗봇 상품 추천 경험, 온라인 상품 비교 친숙도.
3. 첫 과제: 두 예산을 모두 확인하고 상품 하나 또는 미선택을 확정한다.
4. 첫 사후 설문: 이해도 객관식 2개와 확신·어려움 평정 2개가 필수. 설명·결정 근거·어려웠던 정보의 자유 응답 3개는 선택, 각 1,000자 이내.
5. 휴식 후 두 번째 과제와 같은 사후 설문을 수행한다. 사후 설문에서는 상품 선택을 변경하지 못한다. 정답 피드백은 제시하지 않는다.
6. 최종 비교: 첫/둘째 화면, 차이 없음, 판단 어려움 중 선택(필수); 이유(선택).
7. 완료 또는 중단 기록을 JSON으로 내려받아 담당자에게 직접 전달한다. 자동 서버 제출은 없다.

모든 선택지에 기본 응답을 두지 않는다. 연령대 외 실명·연락처를 요청하지 않으며, 자유 응답에도 개인정보를 넣지 않도록 안내한다. 사전 설문은 사전 만족도 측정이 아니며 배경 변수로 사용한다. 본 실험 전에 모집·동의·보관 기간·전달 방법을 연구 담당자가 정한다.

## 데이터 및 분석
- 버전: `pass-explanation-pilot-v3-pre-post`. v2의 pressure 항목은 제거했다. 이전 버전과 같은 설문으로 합쳐 분석하지 않는다.
- `preSurvey.answers`: 사전 응답. `trials[].answers`: 과제별 사후 응답. `finalSurvey.answers`: 최종 비교와 선택적 이유.
- `finalSurvey.preferredCondition`: 실제 배정 순서에 따라 A/B로 변환한 선호. 차이 없음·모름은 null.
- `taskDurationMs`: 과제 시작부터 선택 확정까지. `surveyDurationMs`: 사후 설문 시간. `durationMs`: 둘의 합. `selectionMs`: 마지막 상품 선택까지 경과 시간.
- 시간에는 숨겨진 탭의 시간이 포함된다. 전체 세션에는 사전·휴식·최종 설문이 포함되므로 순수 결정 시간으로 해석하지 않는다.
- `comprehensionCorrect`, `candidateCountCorrect`: 같은 추천 엔진에서 계산한 정답과 비교. 자유 응답은 자동 채점하지 않는다.
- 자유 응답은 최종 텍스트만 저장하고 타이핑 이력은 이벤트에 남기지 않는다. 대화 원문은 수집하지 않는다. 파일에는 문항, 응답 코드·라벨, 과제 정의가 포함된다.
- 중단 세션과 미완료 응답은 별도로 보존한다. `complete`는 최종 비교까지 마친 경우만 해당한다.
- 이해도 정답률과 평정 분포, 참가자별 B−A 차이, 순서·과제·미선택 여부를 함께 본다. 파일럿의 작은 표본만으로 일반적 효과·통계적 유의성을 주장하지 않는다.
- 자유 응답을 조건별로 분류해 이해에 도움이 된 점과 혼란을 만든 점을 정리한다. 설문 답변만으로 인과를 단정하지 않는다.

문항의 정확한 내용과 응답 코드는 `lib/study-surveys.mjs` 및 내보낸 JSON의 `surveyDefinitions`를 기준으로 한다.
