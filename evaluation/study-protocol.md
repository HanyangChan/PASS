# PASS 설명 비교 파일럿 v2 — 선물 하나

## 구현 범위

`/study`는 일반 대화와 분리된 참여자용 화면이다. 사전 정의된 상황 두 개에서 상품을 선택하고 질문에 답한다. 자유 대화·조건 추출 성능은 이번 실험에서 측정하지 않는다. 일반 앱의 대화 기능과 추천 로직은 유지한다.

- A: 상품 가격·기본 추천 근거만 제공.
- B: A와 동일한 상품·근거에 예산 조건의 대조/반사실 설명 추가.
- 동일 과제·예산에서 A와 B는 동일한 전체 후보와 순서를 보여준다. 양쪽 모두 처음/비교 예산 버튼을 쓸 수 있다. B의 추가 정보만 다르다.
- 예산 선택은 적용된 상태이고, B의 설명은 두 고정 예산의 비교다. B 설명을 읽는 것만으로 예산이 바뀌지 않는다.
- 두 과제는 부모님 선물 하나(배송비 포함 30,000→42,000원), 친구 선물 하나(60,000→72,000원)다. 현재 코드의 `pass-explanation-pilot-v2-single-gift` 버전을 기준으로 한다.
- 현재 카탈로그에서는 두 과제 모두 첫 추천이 유지되고 후보 수가 늘어난다. 따라서 ‘첫 추천 변경’ 상황 전체로 일반화할 수 없다. 다른 결과 유형과 과제 난이도는 후속 설계·파일럿 검토가 필요하다.

## 배정과 과제 절차

시작 시 4개 순서 중 균등 무작위 배정한다: 과제1-A→과제2-B, 과제1-B→과제2-A, 과제2-A→과제1-B, 과제2-B→과제1-A. 각 조합은 과제·조건·순서를 균형 있게 포함하지만, 실제 모집 인원이 자동으로 균등 배정되는 것은 아니다. 학습·순서 효과는 분석에서 확인한다.

1. 기록 안내를 읽고 참여 시작을 선택한다. 무작위 세션 ID 외 식별정보를 입력하지 않는다.
2. 두 예산의 후보를 살펴보고 하나를 선택한다. 선택하지 못함도 기록할 수 있다.
3. 첫 추천 변화에 대한 이해 질문(달라짐/같음/모름), 난이도·확신·지출 압박 1~5점에 답한다. 기본 응답은 없다.
4. 응답 제출 후 두 번째 과제를 별도로 시작한다. 중간 휴식 시간은 두 번째 과제 시간에 포함하지 않는다.
5. 종료 또는 중단 후 JSON을 저장한다. 자동 업로드·저장·타 서비스 전송은 없다. 새로고침·페이지 이탈은 미저장 데이터 소실로 이어진다. 파일 전달은 참여자가 직접 한다.

## 로그·분석 정의

- 과제별 설명 조건, 과제 ID, 예산 변경 이벤트, 선택 상품(또는 none), 응답, 제출 및 중단을 기록한다.
- 첫 과제 시작 이후 각 이벤트의 경과 밀리초와 과제 소요 시간을 기록한다. 소요 시간은 과제 읽기·상품 탐색·설문 응답을 포함하며 백그라운드 탭 시간도 포함한다. 순수 결정 시간이라고 부르지 않는다.
- `selectionMs`는 마지막 선택까지의 경과 시간으로 설문 응답 중 선택을 바꾸면 갱신된다. 선택 유효 여부는 selectedId를 기준으로 한다.
- `trials`는 제출한 과제만 포함한다. `status: stopped`와 `current`는 중단/미완료 분석에 사용하고 완수율 분모에서 제외하지 않는다. 다른 조건의 미완료 쌍은 완전쌍 비교와 구분한다.
- `comprehensionCorrect`는 같은 추천 엔진으로 계산한 실제 첫 추천 변화와 응답을 비교한다. 과제 사이에는 정답을 보여주지 않는다.
- 난이도(effort): 1 매우 쉬움~5 매우 어려움; 확신(confidence): 1 전혀 없음~5 매우 높음; 지출 압박(pressure): 1 전혀 없음~5 매우 높음. 자체 문항이며 검증된 척도로 주장하지 않는다.
- export에는 프로토콜 버전, 무작위 배정, 과제 정의도 포함한다. 참가자 원문 발화, 이름, 연락처, 계정 ID는 수집하지 않는다.

## 연구자가 준비할 일

팀원·수업 지침에 맞는 모집 및 동의 절차를 별도로 준비한다. 이 UI의 확인 스위치만으로 정식 연구 동의 절차가 완료된다고 간주하지 않는다. 로그 파일 전달 방법·보관 기간을 정하고 참여자가 이해할 수 있게 설명한다. 고령 참여자의 읽기·조작 어려움은 실제 파일럿으로 확인한다.

분석 전 과제 순서·조건별 완수율, 이해 질문, 난이도·확신·지출 압박, 선택 예산, 소요 시간의 비교 계획을 고정한다. 작은 파일럿 결과는 기술통계와 오류 사례로 보고한다. 효능·신뢰도 향상·통계적 유의성은 데이터 없이 주장하지 않는다.

2026-09-21: 지표 계산법, 미완료·중복 처리, 완전쌍 비교 및 보고 표를 [분석 계획](analysis-plan.md)에 정리했다. 실제 데이터 수집·분석은 아직 수행하지 않았다.

## 구현 검증

설명 조건 간 동일 결과, 4개 순서의 균형, 입력 검증, 예산 축소에 따른 선택 무효화, 중복 제출 방지, 휴식 제외, 중단과 내보내기를 자동 테스트한다. 브라우저 상호작용·파일 다운로드·실사용자 평가는 아직 수행하지 않았다. 실제 모집 전 해당 검증이 남아 있다.
