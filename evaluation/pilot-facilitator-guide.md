# PASS 사용자 파일럿 진행자 안내 초안

2026-09-21 작성. 실제 모집·동의·평가는 미실시. 수업 지침과 팀원 검토 후 확정한다.

## 실시 전 확인

1. 브라우저에서 완료·중단 JSON 파일이 실제 저장되고 열리는지 확인한다. 현재 내장 브라우저의 다운로드 확인이 미완료이므로 모집 전 해결한다.
2. 담당자, 연락 방법, 파일 전달 경로, 접근 가능한 팀원, 보관 종료일과 삭제 일정을 정한다. 미정 상태에서 참여자에게 보관 방식을 약속하지 않는다.
3. 팀원끼리 과제 문구와 [분석 기준](analysis-plan.md)을 검토한다. 합성 QA 파일은 실제 참여 데이터와 분리한다.
4. 설명 읽기와 스마트폰 조작 경험이 다른 참여자를 포함하도록 모집안을 정한다. 고령 참여자의 나이만으로 디지털 능력을 추정하지 않는다.

## 참여 안내 문안

“이 활동은 명절 선물 추천 설명이 이해하기 쉬운지 알아보는 수업용 평가입니다. 가상 상품을 고르는 과제 두 개가 있으며 실제 결제는 없습니다. 여러분의 능력을 시험하는 것이 아닙니다. 선택, 예산 변경, 설문 응답, 소요 시간이 기록되며 언제든 중단할 수 있습니다. 이름과 연락처는 앱에 입력하지 않습니다. 기록은 자동 제출되지 않으며 마지막에 저장한 파일을 정해진 방법으로 전달합니다. 전달·보관 방법을 설명받은 뒤 참여 여부를 결정하실 수 있습니다.”

## 진행 순서

- 안내와 질문 시간을 제공하고 수업 지침에 맞는 참여 동의를 확인한다.
- 화면을 직접 읽고 시작하게 한다. 진행자는 추천 정답이나 특정 상품을 알려주지 않는다.
- 조작 도움을 요청하면 필요한 버튼 위치만 안내하고, 도움 시점·종류를 관찰 기록에 남긴다. 대답이나 선택을 대신하지 않는다.
- 시간 지표를 수집하는 본 과제 중에는 계속 말하도록 요구하지 않는다. 설명을 위한 중단이나 기술 장애는 따로 기록한다.
- 두 과제가 끝나거나 중단되면 JSON을 저장하고 실제 파일을 확인한다. 파일을 전달하지 않겠다는 선택도 존중한다.
- 종료 후 “어떤 설명이 선택에 도움이 되었나요?”, “예산을 바꾸면 무엇이 달라진다고 이해했나요?”, “어디에서 망설였나요?”를 묻는다. 유도 질문은 피한다.

## 진행자 기록 양식

|항목|기록|
|---|---|
|익명 세션 ID / 앱 버전| |
|기기·브라우저 / 배정 그룹| |
|시작 / 완료 / 중단 / 파일 확보 여부| |
|도움 요청 시점·내용| |
|기술 장애·비활성 시간 등 시간 해석 요인| |
|이해하기 어려웠던 문구·조작| |
|사후 의견(개인정보 제외)| |

실명·연락처를 이 기록표에 적지 않는다. 미완료나 파일 미확보를 성공 사례에서 제외해 숨기지 않는다. 사용자 결과는 수집 후 작성하며 자동 테스트 통과를 사용성 향상 근거로 사용하지 않는다.
