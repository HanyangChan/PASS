## 남은 차단 항목

일반 Chrome/Safari에서도 JSON 저장을 실행하고 실제 파일을 열어 version, status, trials, events를 확인해야 한다. 내장 브라우저 제한인지 앱 저장 문제인지 현재 관찰만으로 단정할 수 없다. 저장 검증 전 참가자 모집을 시작하지 않는다. A/B 화면·과제·비교 로그 작업은 진행 중으로 유지한다.

## 후속 QA 체크

- 완료 파일: status=complete, trials 2개, A/B 각각 1개, none과 unsure 응답 보존.
- 중단 파일: status=stopped, trials 0개, start/stop 이벤트, 미완료 current 보존.
- 과제 사이 중단, 실제 휴식 시간 제외, 파일 중복 저장은 별도 확인.
- 모바일 화면과 실제 고령 사용자 조작은 아직 미검증.
