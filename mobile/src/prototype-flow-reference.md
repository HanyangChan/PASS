# 첨부 화면 흐름도 반영

사용자가 제공한 전체 화면 흐름도를 프로토타입 인터랙션 참고 자료로 사용한다. 작은 화면 속 문구를 정확하게 확인할 수 없는 부분은 기존 앱 문구와 데이터로 구성한다.

## 연결한 흐름

- 홈 → AI 추천 → 조건 요약·수정 → 추천 카드 → 상세
- 상세 → 선물 확인 → 판매처 이동 확인(체험) → 구매 완료 확인(체험) → 완료 → 홈/다른 선물 찾기
- 마이/홈 로그인 버튼 → 로그인 체험 → 입력 오류/성공 → 마이 → 계정·선물 준비 기록 → 로그아웃
- 로그인 → 비밀번호 표시 전환, 비밀번호 찾기·회원가입 안내, 게스트 둘러보기
- 랭킹 → 검색/받는 분 구분 → 정렬·가격·상품군 필터 → 적용/초기화/취소 → 상세
- 채팅 → 첨부 선택(카메라/앨범/PDF 예시) → 첨부 제거/전송
- 채팅 → 음성 입력 시작·완료·내용 수정·재시도·입력 적용
- 채팅 → 조건에 맞는 결과 없음 → 예산 또는 제외 조건 조정
- 채팅 → 조건 비교 → 기존 예산 비교·변경 적용
- 홈/AI 추천/랭킹/마이 하단 내비게이션

## 프로토타입 범위

실제 인증·파일 접근·음성 인식·판매처 이동·결제는 수행하지 않는다. 로그인은 이메일 형식과 임의 비밀번호 길이로 성공/실패 화면만 체험한다. 계정 체험 상태와 선물 준비 기록은 메모리에만 남는다. 찜과 최근 본 상품은 기존 기기 저장 기능을 유지한다. 설문은 비활성 상태를 유지한다.

## 추가 보완 항목

- 참조 화면의 연령·성별 분류, 포장·배송 필터는 상품 메타데이터와 함께 확장한다.
- 네트워크 오류·재시도 화면의 별도 체험 상태는 아직 추가하지 않았다.
- 첨부 파일에서 조건 추출을 확인하는 단계는 현재 예시 첨부 안내로 대체했다.
- 로그인 이후 여러 대화의 저장·선택 화면은 현재 완료 기록과 찜/최근 기록으로 일부만 구현했다.
- 조건 비교는 기존 예산 비교 화면을 재사용했다. 배송/포장 비교 탭의 구성은 별도 보완한다.
- Figma 새 파일의 접근 권한이 확보되면 정확한 문구·간격·구성을 다시 대조한다.
