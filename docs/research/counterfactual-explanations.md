# 무이력 세션 개인화와 대조·반사실 추천 설명

## 프로젝트의 두 축

1. 무이력 세션 개인화: 로그인·구매 이력 없이 현재 대화의 명시적 조건을 누적한다.
2. 대조·반사실 설명: 현재 추천과 대안의 차이, 조건을 변경했을 때 실제로 계산되는 결과를 보여준다.

턴별 조건 변경 표시는 두 축을 지원하는 인터페이스로 유지한다. 새로운 알고리즘이나 업계 최초를 주장하기보다, 한국어 명절 선물 과제에서 조건 이해와 선택 과정에 미치는 효과를 검증한다.

## 쉽게 말하면

대조 설명은 “왜 지금은 이 상품이고 저 상품은 아닌가요?”에 답한다. 반사실 설명은 “예산만 바꾸면 결과가 어떻게 달라지나요?”에 답한다. 이 데모에서 반사실은 추천 프로그램에 가상 조건을 넣어 재실행한 결과이며, 실제 사람의 행동에 관한 인과 추론은 아니다.

예를 들어 “한 세트, 상품값 3만 원 이하”에서는 39,000원 상품이 예산 초과다. 가상 상한을 39,000원으로 바꾸면 그 상품이 후보가 될 수 있다. 현재 상품이 더 저렴해 순위가 유지되면 “대신 추천됩니다”가 아니라 “후보가 추가됩니다”라고 설명한다. 후보 확대는 추천 결과 자체가 바뀌는 엄밀한 반사실과 구분해 기록한다.

## 구현 규칙

- 변경할 수 있는 가상 조건은 `budget.amount_krw` 한 개다. 예산 기준·수량·배송비·선호·배송일·제외 조건은 고정한다.
- 일반 추천과 가상 추천은 동일한 필터·점수·동점 정렬 함수를 사용한다.
- 예산 외 조건을 통과하는 상품의 비용 임계값을 구한다. 현재 상한을 넘는 서로 다른 임계값 중 작은 두 개를 표시한다.
- 각 임계값에서 전체 추천을 다시 계산하고, 해당 임계값에서 새로 자격을 얻은 상품 중 순위가 가장 높은 하나를 비교 대상으로 선택한다.
- 임계값은 해당 상품이 비용 조건을 통과하는 최소 상한이다. 모든 조건 조합 중 최소 변화나 최고 효용을 찾았다는 주장은 하지 않는다.
- 세트당 예산은 한 세트 비용, 총예산은 세트 수를 곱한 비용과 비교한다. 배송비 포함이면 각 세트의 배송비를 더한다.
- 수량·배송비 여부가 미확정이면 비교를 보류한다. 알레르기 정보 부족은 예산 변경으로 해결하지 않는다.
- 카드 조회는 세션 상태를 수정하지 않는다. “이 예산으로 적용하기”를 누르면 그 상한만 적용하고 대화·조건 패널·변경 내역·추천을 함께 갱신한다.

## 네 가지 결과 구분

| 값 | 사용자에게 보여주는 의미 |
| --- | --- |
| first_match | 현재 후보가 없지만 변경 후 추천 가능한 상품이 생김 |
| top_changed | 첫 번째 추천이 바뀜 |
| top_three_changed | 첫 번째를 유지하면서 추천 3개 구성이 바뀜 |
| eligible_only | 추천 3개는 동일하고 선택 가능한 후보만 추가됨 |

다른 조건 때문에 추가 후보가 없거나 현재 예산이 이미 모든 후보를 포함하면 대안을 꾸며내지 않는다. 비싼 상품이라는 이유로 더 좋은 품질·건강 적합성·만족도를 주장하지 않는다. 포장·단맛·도착일은 데이터에 기록된 차이만 표시한다.

## 평가 설계

주요 질문: 대조·가상 조건 설명은 한국어 명절 선물 과제에서 추천의 제약과 조건 변경 결과를 이해하는 데 도움이 되는가?

A는 단일 상품 근거 설명, B는 동일한 추천에 대조·가상 조건 설명을 추가한다. 상태 패널과 턴별 diff는 양쪽에서 동일하게 고정하여 비교 설명의 효과와 혼동하지 않는다. 사용자 평가용 A/B 조건 배정과 로그 수집은 아직 구현하지 않았다.

- 기술 검증: 설명한 상한에 도달했을 때 해당 상품이 실제 후보가 되는 비율, 표시한 추천 구성과 재계산 결과 일치율, 다른 필수 조건 위반율, 현재 상태가 적용 전 유지되는지.
- 사용자 평가: “예산을 바꾸면 1위가 바뀌는가, 후보만 늘어나는가?” 정답률, 배제 이유 이해도, 조건 조정 과제 완료 시간·턴 수. 신뢰·만족도는 보조 설문이다.
- 비교 표현 자체가 추가 지출을 유도할 가능성도 있으므로, 비용 변화와 사용자의 선택을 함께 관찰한다. 예산 증액의 필요성을 주장하지 않는다.
- 명절 선물 맥락의 한국어 사용자로 평가하되 개발용 10개 대화와 별도 평가 대화를 사용한다. 신뢰 향상은 결과가 나오기 전에는 가설이다.

## 검증 범위와 선행연구

추가된 자동 테스트는 후보만 확대되는 경우, 실제 1위/상위 3개 변경, 수량·배송비, 제외·포장·배송일 유지, 적용 후 재현성, 알레르기와 정보 부족, 대안 없음, 금액 계산 오류를 다룬다. 현재 카탈로그는 같은 가격대가 반복되므로 예산 증액 후에도 기존 상위 추천이 유지되는 경우가 많다. 이 한계를 감추기 위해 순위를 바꾸지 않는다.

제안에 포함된 CECR의 최초성·발표 정보와 국내 서비스의 기능 부재는 이 작업에서 원문 조사로 검증하지 않았다. 논문·포스터에 인용하기 전에 정확한 원문과 서비스 문서를 확인해야 한다. 검색에서 발견하지 못했다는 사실은 기능이 존재하지 않는다는 증거가 아니다.
