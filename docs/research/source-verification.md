# 선행연구·국내 서비스 근거 확인

조사일: 2026-09-22. 공개 원문·저자 페이지·공식 발표에 대한 한정 조사이며, 모든 서비스 기능을 직접 시험한 전수조사가 아니다.

## 수정해야 할 주장

|기존 표현|판정|사용할 표현|
|---|---|---|
|반사실 추천 설명은 2023년에 처음 등장했다|범위가 너무 넓음|대화형 추천과 관련된 CECR 연구가 있으나 추천 분야 반사실 설명 연구는 그 이전에도 존재한다.|
|CECR가 최초임이 입증됐다|저자 주장과 독립 검증을 혼동|CECR 저자는 대화형 추천에 반사실 기법을 최초 접목했다고 주장한다. 본 조사에서 최초성을 독립 검증하지 않았다.|
|사람은 비교 설명을 더 직관적으로 이해한다|일반적인 대조 설명 논의만으로 PASS 효과를 확정할 수 없음|대조적 설명에 관한 이론적 근거가 있으며 PASS의 이해도·난이도 효과는 사용자 실험으로 확인한다.|
|국내 쇼핑 챗봇 어디에도 이 기능이 없다|자료에 없는 것과 기능 부재는 다름|아래 확인 자료만으로 고정 조건을 보존한 예산 재계산 카드의 제공 여부를 확정하지 못했다.|
|대화 개인화 또는 규칙+LLM 조합 자체가 고유한 기술이다|유사 접근 존재|PASS의 연구 초점은 한국어 선물 상황의 조건 확인·비교 설명 인터페이스와 그 평가다.|

## 연구 근거

1. **Dianer Yu, Qian Li, Xiangmeng Wang, Qing Li, Guandong Xu, Counterfactual Explainable Conversational Recommendation (CECR).** [공동저자 연구 목록](https://chrystalii.github.io/publications)에서 제목·저자·TKDE 2023 표기 및 대화형 추천 최초 접목이라는 저자 주장을 확인했다. 연결된 IEEE 원문 열기는 실패했다. 따라서 세부 알고리즘·실험 결과·최종 권호 발행 연도는 이번 확인으로 확정하지 않는다. PASS의 예산 재계산 구현을 CECR 재현이라고 부르지 않는다.
2. **Xiangmeng Wang 외, Reinforced Path Reasoning for Counterfactual Explainable Recommendation.** [저자 공개 논문](https://arxiv.org/abs/2207.06674), 2022년 공개본. 상품 속성 기반 반사실 설명 연구가 2023년 이전에도 있었음을 보여준다. 대화형 추천 최초 여부를 직접 반박하는 근거로 확대하지 않는다.
3. **Tim Miller, Contrastive Explanation: A Structural-Model Approach.** [저자 공개 논문](https://arxiv.org/abs/1811.03163), 2018년 공개본. 설명을 다른 대안과의 대조로 다루는 이론적 배경이다. 한국 고령 사용자의 상품 선택 성능이나 특정 UI 효과를 검증한 연구로 인용하지 않는다.
4. **Park 외 (Kakao), A Practical Approach for Building Production-Grade Conversational Agents with Workflow Graphs.** ACL 2025 Industry Track, pp.1508–1519, DOI 10.18653/v1/2025.acl-industry.107. [학회 서지·초록](https://aclanthology.org/2025.acl-industry.107/), [논문 PDF](https://aclanthology.org/2025.acl-industry.107.pdf). PDF pp.1–2에서 메신저 기반 선물 탐색과 DAG·LLM 하이브리드 접근을 확인했다. PASS의 규칙 우선 경로와 구조가 동일하다는 뜻은 아니지만, 하이브리드 대화형 커머스 자체의 고유성 주장은 지지하지 않는다.

검색 결과의 2차 기사·블로그는 기술 주장 근거로 채택하지 않았다. 기업 발표는 발표 시점의 설명이며 조사일 현재 모든 계정에서 동일하게 제공되는지 직접 검증하지 않았다.

## HCI 과제에 사용할 프로젝트 설명

PASS는 로그인·구매이력 입력 없이 현재 한국어 대화의 조건을 갱신하고, 가상 명절 식품 카탈로그에서 선물을 추천하는 연구용 프로토타입이다. 다른 조건을 유지한 채 예산만 바꾸어 다시 계산하고, 추천 순위 변화와 후보 확대를 구분해 보여준다. 연구 질문은 이러한 비교 설명이 기본 추천 근거만 제공하는 화면보다 조건 이해와 선택 확신을 돕는지, 추가적인 인지 부담이나 지출 압박을 주는지다. 효과와 한국 사용자 적합성은 아직 검증 전이다.

현재 두 파일럿 과제는 첫 추천이 유지되는 유형이다. 따라서 이 파일럿만으로 추천 순위가 바뀌는 모든 반사실 설명의 효과를 주장하지 않는다. 무이력 조건은 서비스 전체 학습 데이터가 없다는 뜻이 아니라 PASS가 사용자의 구매이력을 입력으로 요구하지 않는다는 뜻이다.
