A와 B는 같은 카탈로그·모델·시나리오의 이전 기록을 사용했다. C와 시간대가 달라 응답 시간은 세션별 공급자 상태의 영향도 받는다.

같은 모델의 B보다 C의 추정 비용은 DeepSeek 기준 약 19%, GPT 기준 약 23% 높다. C의 중앙 응답 시간과 p95도 모두 A·B보다 높았다.

기존 C와 개선 C는 서로 다른 세션에서 실행했다. 지연에는 공급자 응답 시간과 로컬 Worker 처리 시간이 포함된다. 제조사 성분 근거는 4개 ASIN을 확인했다. 비용은 사용자 제공 단가를 적용했다.
