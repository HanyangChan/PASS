## 해석 범위

24개 고정 문구를 세 번 반복한 내부 회귀 평가다. 이미 수정에 사용한 과제를 포함하므로 새로운 문구/사용자의 일반 정확도라고 부를 수 없다. A는 규칙으로 처리한 요청에 모델 호출이 없어 평균이 낮다. 공정한 제품 구조 비교이지만 같은 호출 수/토큰 예산 비교는 아니다(B 최대 6회, C 최대 10회, 전체 20초). C 개선이 있더라도 검토만의 효과와 추가 계산량 효과를 분리하지 못한다.

이전 DeepSeek 결과와는 코드·규칙·향 필터·추론 설정이 달라 모델 교체만의 효과를 계산할 수 없다. 이번 결과는 현재 코드에서 Luna A/B/C를 서로 비교한 수치다. 공급자 캐시/게이트웨이/네트워크 변동과 작은 표본을 고려해야 한다. 단가는 계산하지 않았고 토큰 사용량은 공급자 반환값이다.

로컬 프로토타입도 Luna + 추론 비활성으로 변경했다. 운영 배포는 하지 않았다. 원문/기대 조건/실패 검사/모델 응답 ID/소스 해시는 [원본 JSON](./luna-comparison-2026-11-06.json)에 있다.
