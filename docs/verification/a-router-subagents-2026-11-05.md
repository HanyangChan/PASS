# A안 서브 에이전트 구현 검증 — 2026-11-05

Supervisor·수령인 분석·상황/명절·소비 성향·취향 분석·종합 판단의 초기 구현과 API 연결을 확인했다. 공통 엔진·다른 에이전트 폴더·모바일 UI는 변경하지 않았다. [결과 원본](a-router-subagents-2026-11-05.json).

## 실제 전체 파이프라인

고정 합성 입력에서 은사님·생신·격식 포장·차 선호·우유 회피·배송비 포함 5만원을 지정했다. 실제 `deepseek-v4-flash`가 네 전문 역할을 선택했고, 병렬 분석과 종합·최종 검증까지 통과했다.

- 논리 호출: Supervisor 1 + 전문 역할 4 + 종합 1 = **6회**, 실제 HTTP **6회**.
- 단일 사례 총 지연: **5.08초**.
- 공급자가 보고한 합계: 입력 4,922, 출력 673, 총 5,595토큰.
- 실제 반환 조건: 수령인 은사님, 상황 생신, formal 포장, `category:coffee_tea`, 우유 제외, 예산 50,000원·배송비 포함.

플랫폼은 DeepSeek를 OpenRouter 호환 경로로 중계하므로 `reasoning.enabled=false`를 사용했다. `reasoning_effort=none`만으로는 비사고 전환이 되지 않았고, 공급자 직접 전용 `thinking` 옵션은 플랫폼에서 거부됐다. 지원되는 호환 옵션으로 실제 응답을 확인했으며 내부 추론은 저장하지 않는다. 공통 LLM 모듈의 기본값은 변경하지 않았다.

## 같은 입력의 단일/서브 모드 비교

같은 합성 입력·상태·상품·모델에서 두 모드 모두 명시적으로 비사고 설정을 사용했다. 각 모드의 시나리오 **10/10**이 통과했다.

| 항목 | single | subagents |
| --- | --- | --- |
| 규칙·설명·비교 경로 | 실제 모델 0회 | 실제 모델 0회 |
| 자유 발화 논리 호출 | 1회 | 3회 |
| 자유 발화 지연, 단일 표본 | 0.96초 | 3.04초 |
| 자유 발화 총 토큰 | 1,259 | 2,159 |
| 선택한 전문 역할 | 해당 없음 | taste |

이 사례에서는 같은 조건 검사를 통과하면서 서브 모드의 지연·토큰이 늘었다. 일반적인 정확도 향상·평균 지연·비용 우위를 입증하지는 않는다. 운영 기본값은 `single`로 유지하고, 로컬 API만 명시적으로 `subagents` 시험 모드로 실행했다.

## 확인 범위와 남은 검증

전체 파이프라인 시험은 합성 입력·상품으로 실제 공급자에 호출했다. 비교 audit는 실제 Worker 핸들러를 쓰되 인증·카탈로그·계정은 메모리 안의 합성 대체물이다. 실제 사용자의 기록은 수정하지 않았다.

실행 중인 로컬 `/health`는 200이고 `a-router`, `subagents`, `deepseek-v4-flash`, 상품 3,376개를 확인했다. 브라우저 자동 제어 연결과 네이티브 앱 제어가 허용되지 않아 **현재 화면의 사용자 입력부터 렌더링까지는 자동 확인하지 못했다**. 실제 Supabase 인증·사용자 화면·음성·첨부 동작은 별도 수용 확인이 필요하다. 기존 모바일 테스트 통과를 실기기 검증으로 표시하지 않는다.

서버 영속 상태·CAS·장기 기억 자동 저장·운영 배포는 추가하지 않았다. 자연어와 근거의 의미적 일치를 모든 문장에 보장하지 않으며, 성분 누락 보조 검사는 알려진 제한된 표현을 대상으로 한다.

## 다시 실행

```sh
npm run test:subagents
npm run smoke:subagents
LLM_REASONING_ENABLED=false A_ROUTER_LLM_MODE=single npm run audit:router
LLM_REASONING_ENABLED=false A_ROUTER_LLM_MODE=subagents npm run audit:router
```

`smoke`와 `audit`의 자유 발화는 실제 플랫폼 사용량을 발생시킨다. 설정·호출 상한·모드 전환은 [A안 README](../../baseline/agents/a-router/README.md)를 따른다.
