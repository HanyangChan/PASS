# DeepSeek V4 Flash A 개선 전후 비교

동일한 영문 Amazon 카탈로그 30만 개와 동일한 채점 버전 2를 사용했다. 버전별로 시나리오 120개를 3회 반복해 360회, API 요청 450건을 기록했다. 기존 A와 개선 A는 서로 다른 날짜에 각각 단독으로 순차 실행했다. 응답 시간에는 모델 공급 상태가 반영될 수 있다. 시나리오에는 개선에 사용한 사례가 포함된다.

같은 시나리오와 반복 번호를 짝지으면 정확 상품 Top 3 성공으로 바뀐 건 3건, 실패로 바뀐 건 0건이다. 제조사 성분 근거는 4개 ASIN에 한정된다.

모델 시도는 414회에서 162회로 줄었다. 기존 A는 한 시도에서 토큰 사용량을 받지 못했다. 정확 상품 평가의 사용자 요청에는 상품명이나 모델 설명이 들어 있고 ASIN은 채점 데이터에만 있다. 명시적 ASIN 조회 경로는 별도 로컬 API 테스트로 확인했다.
